# 工作提醒器

适用于 Windows 10 / 11 的本地桌面工具。双击 `WorkReminder.exe` 或桌面上的“工作提醒器”快捷方式即可打开。关闭主窗口后程序仍在系统托盘运行；通过左下角退出按钮或托盘菜单退出才会停止提醒。

## 日常工作

1. 在左侧选择项目。可新建项目，并填写负责人、工作目标、衡量标准、计划完成日期和风险与所需支持。“全部项目”汇总展示；在此视图新建事项时，可在右侧选择所属项目，默认“未归类”。
2. 在右侧填写工作事项、提醒时间和可选的计划完成日期，点击“保存提醒”。提醒到点弹窗、延后或直接关闭都不会把事项标为完成；直接关闭弹窗默认延后 10 分钟。
3. 工作做完后勾选该行的“完成”复选框，或在弹窗点击“本项已完成”。单次事项会保留为“已完成，待安排下一步”，并停止当前步骤的提醒。
4. 选中已完成的末尾事项，可以“添加下一步”，填写新事项及独立提醒时间；也可以明确点击“没有后续，闭环”。不填写下一步不会自动闭环。已闭环事项在归档前仍能重新添加下一步。
5. 每天、周一至周五、每周重复事项完成时会保留本次完成记录，并自动生成下一次。未编辑的自动下一次可选中后点击“结束重复并闭环”。已编辑或已推进的事项需要按普通步骤处理。
6. 选中事项可在右侧查看整条工作链的顺序、备注、提醒与完成时间。移动项目会移动该链的全部当前步骤。只有没有当前或归档事项引用的空项目可删除。

“全部待办”显示未完成事项与待安排下一步的末尾事项；“待安排下一步”集中显示尚未决定后续的工作；“已完成”显示当前数据中的所有已完成步骤。重复事项的工作日规则只排除周六、周日，不处理法定节假日和调休。

## PBC 汇报

在左侧选中项目后点击“导出 PBC”，导出该项目及其事项；选择“全部项目”会按项目分组导出。可在“导出设置”选择本周、本月或自定义日期。首次导出选择输出文件夹，此后沿用该目录和周期模式。本周、本月的具体日期每次导出时重新计算。

每次导出创建一个独立目录，包含可打印的 `PBC汇报.html` 和可编辑的 `PBC汇报.md`。汇报包含目标、衡量标准、本期成果、风险与支持、下一步计划、当前工作状态、闭环记录和事项明细，并读取已有归档。完成数量仅是工作统计，不会自动计算绩效得分。成果和依据未填写时会明确标注；历史时间未知的记录不计入本期完成数。HTML 可在浏览器中打印为 PDF。程序不会自动发送汇报文件。

## 归档与备份

当前数据位于 `%LOCALAPPDATA%\WorkReminder\tasks.json`；每次保存会生成上一个版本的 `tasks.json.bak`。旧版数据首次用新版程序打开时，先保存 `tasks.json.pre-migration-*` 完整快照，再迁移到版本 2。旧事项归入“未归类”；旧已完成事项为“待安排下一步”，不会推断闭环时间。

需要清理已闭环的工作链时，先正常退出程序，再在本目录运行：

```powershell
pwsh -File .\archive-completed.ps1
```

脚本仅将**明确闭环的完整工作链**移入同一数据目录的 `archive.json`，保留所有步骤及项目名称快照；仅完成但尚未明确闭环的事项不会归档。归档前会生成 `tasks.pre-archive-*` 完整快照。旧归档继续保留，PBC 汇报仍可读取。若数据损坏，程序或脚本会报错并保留原文件；请先另存损坏文件，再考虑从 `.bak` 或快照恢复。

开机启动可在左下角开启，默认关闭。数据仅在本机保存，不联网同步。电脑关机、休眠或程序退出期间不能弹窗；恢复运行后会提醒仍未完成的到期事项。

## 开发与验证

源码使用 C#、WPF、.NET Framework 4 和 PowerShell，编译器来自 Windows 系统目录，无 NuGet 或网络依赖。测试使用隔离数据目录，不会写入正式待办。

```powershell
pwsh -File .\build.ps1
pwsh -File .\verify-ui.ps1
pwsh -File .\ArchiveTests.ps1
pwsh -File .\verify-system.ps1
```

`build.ps1` 编译程序并运行核心与报告测试；`verify-ui.ps1` 测试真实 WPF 窗口并将截图保存到 `verification/`；`ArchiveTests.ps1` 测试整链归档和旧归档兼容；`verify-system.ps1` 验证后台运行、托盘、单实例与退出。运行系统测试前须退出正式程序。
